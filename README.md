# 郁离 · 未完成的世界（第二版）

这是一个个人数字美术馆式网站，采用诧寂色调、文学排版、滚动显现和 Canvas 模拟纸张燃烧的转场效果。

## 本地预览
解压后双击 `index.html`，或用 VS Code / Live Server 预览。

## 文件
- `index.html`：页面结构与各展厅入口
- `style.css`：美术馆视觉、响应式布局、弹窗展厅样式
- `script.js`：Canvas 燃烧边缘、火星、导航、内容展厅

## 第二版更新
- 点击处向四周扩张的燃烧遮罩，带不规则焦边、火舌与火星（程序模拟，不是真实火焰）。
- 文学、哲学、心理学、音乐与笛子、园艺、美术、摄影、计算机等独立内容展厅。
- 人物与书籍介绍、阅读问题、兴趣练习、原创“郁离自记”短句。
- 手机触控支持，并尊重系统减少动态效果设置。

## 部署 GitHub Pages
1. 在 GitHub 创建 Public 仓库。
2. 上传 `index.html`、`style.css`、`script.js`、`README.md` 到仓库根目录。
3. Settings → Pages → Build and deployment → Deploy from a branch。
4. 选择 `main` 和 `/(root)`，保存并等待部署。

## 注意
- 字体通过 Google Fonts 加载，离线时会回退到系统字体。
- 名言翻译可能存在版本差异；未确认原文的内容已避免直接伪装成逐字引文。
- 页面里对个人经历的描述基于目前提供的信息；没有虚构具体获奖、阅读完成情况或项目成果。
